# D3 Floorspec

D3 Floorspec, the reference implementation of the [Floorspec](https://github.com/D3Cloud-io/floorspec) house-as-code standard, has moved and is no longer public.

- **Use it:** https://floorspec.d3cloud.io
- **The standard:** https://d3cloud.io/floorspec, source at [D3Cloud-io/floorspec](https://github.com/D3Cloud-io/floorspec)

Links to this repository from Floorspec's registry and conformance fixtures, including frozen drafts, land here on purpose. This repository holds nothing else and is archived.
