# docs

Skeleton. See FLR in Foreman for the tasks that fill this directory.

- [self-host.md](self-host.md) — from a clean machine to a running instance with Docker Compose,
  first-run setup, Sign in with D3 Auth, rule packs, backups, upgrades and Claude Code over MCP.
- [runbooks/restore.md](runbooks/restore.md) — the nightly backup, the weekly restore drill and its
  recorded result, restoring for real, and the alert email for failed backups, drills, deploys and
  health checks.
- [lighting.md](lighting.md) — light levels: lumens per fixture and watts, inverse-square in
  metres, a fixture never shadowing itself, and the exposure every view shares (FLR-T-13.1).
- [camera.md](camera.md) — saved views (FS_views), the lens on a 36 mm frame, two-point perspective
  as a shift lens, depth of field, exposure compensation, framing guides and the shot list (FLR-T-13.10).
- [renovation.md](renovation.md) — remodels (FS_renovation): existing, demolish and new; the Existing,
  Demolition, Proposed and Combined plans in the editor, 3D, PDF and DXF; remodel areas and quantities (FLR-T-18.13).
- [daylight.md](daylight.md) — daylight you can see: illuminance on every floor's work plane in four
  named bands, sun-hours that day and a year, glare at desks and beds; how the worker path-traces it,
  and how accurate it is (FLR-T-14.7). Advisory, always.
